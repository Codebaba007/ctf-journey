## Day 35–39: Secure Network Architecture

### What I Learned

#### 1. Secure Network Architecture
- Understanding how secure networks are designed.
- Learning how network components work together to protect systems.
- Understanding the importance of network segmentation.
- Identifying potential security risks in network designs.

#### 2. Network Segmentation
- Dividing a network into smaller, isolated sections.
- Limiting communication between different network segments.
- Reducing the impact of a compromised system.
- Understanding how segmentation helps prevent lateral movement.

#### 3. Firewalls
- Understanding the role of firewalls in network security.
- Filtering incoming and outgoing network traffic.
- Using firewall rules to control communication.
- Understanding how firewalls help enforce security policies.

#### 4. Network Security Principles
- Applying the principle of least privilege.
- Restricting unnecessary network access.
- Reducing the attack surface.
- Using layered security to protect network infrastructure.

#### 5. Secure Network Design
- Understanding how different network components interact.
- Identifying trust boundaries.
- Designing networks with security in mind.
- Understanding how network architecture can limit the impact of attacks.

### Key Takeaways
- Network architecture plays an important role in cybersecurity.
- Network segmentation helps contain security incidents.
- Firewalls control traffic between networks.
- Least privilege limits unnecessary access.
- Layered security provides multiple levels of protection.

- Firewall fundamentals

## Day 35–39: The Building Blocks of AI

### What I Learned

#### 1. Artificial Intelligence
- Understanding what Artificial Intelligence (AI) is.
- Learning how AI systems perform tasks that typically require human intelligence.
- Exploring the basic concepts behind AI.

#### 2. Machine Learning
- Understanding Machine Learning (ML) as a branch of AI.
- Learning how machines identify patterns from data.
- Understanding the difference between traditional programming and machine learning.

#### 3. Types of Machine Learning
- Supervised Learning: Learning from labeled data.
- Unsupervised Learning: Finding patterns in unlabeled data.
- Reinforcement Learning: Learning through actions, rewards, and penalties.

#### 4. Neural Networks
- Understanding the basic structure of neural networks.
- Learning how artificial neurons process information.
- Understanding the relationship between inputs, weights, biases, and outputs.

#### 5. Deep Learning
- Understanding Deep Learning as a subset of Machine Learning.
- Learning how neural networks with multiple layers process complex data.
- Exploring how deep learning is used in modern AI applications.

#### 6. Data and Training
- Understanding the importance of training data.
- Learning how AI models identify patterns.
- Understanding the basic idea of training and evaluating a model.

### Key Takeaways
- AI is a broad field that includes Machine Learning and Deep Learning.
- Machine Learning allows systems to learn patterns from data.
- Supervised, unsupervised, and reinforcement learning use different learning approaches.
- Neural networks are inspired by the structure of biological neurons.
- Deep Learning uses multiple neural network layers to learn complex patterns.
- Data quality and training are important to AI performance.
