# Day 02 — Computer & Linux Fundamentals

## Overview

Continued my cybersecurity journey by learning how computers work internally
and beginning to work with Linux.

The focus for Day 02 was building practical foundations that will be useful
throughout the rest of my cybersecurity and CTF journey.

## Platform

**TryHackMe**

## Rooms Completed

- Inside a Computer System
- Computer Types
- Linux Fundamentals (Pt 1)

## What I Learned

### Inside a Computer System

Learned the basic components that make up a computer system and how they work
together.

Key concepts included:

- CPU
- RAM
- Storage
- Motherboard
- Input and output
- Operating systems
- How instructions and data are processed

Understanding these components provides a foundation for understanding how
software interacts with the underlying computer.

### Computer Types

Learned about different types of computer systems and how they are used for
different purposes.

This helped me understand that computers are not limited to traditional
desktop or laptop systems. Different systems are designed around different
requirements such as performance, portability, networking, and resource
constraints.

### Linux Fundamentals

Started learning Linux and the command-line environment.

Linux is especially important in cybersecurity because many security tools,
servers, and CTF environments use Linux.

I began learning how to interact with a Linux system through the terminal
instead of relying entirely on a graphical interface.

Important concepts introduced included:

- Linux filesystem
- Directories and files
- Command-line interaction
- Navigating the filesystem
- Basic Linux commands
- Users and permissions
- The importance of the terminal in cybersecurity

## Practical Experience

The most important part of Day 02 was beginning to become comfortable with
Linux.

Instead of treating the terminal as something to memorize, I am learning to
understand what each command does and why it is useful.

This will become important later when working with:

- CTF machines
- Servers
- Networking tools
- Enumeration
- Privilege escalation
- Security utilities

## Key Takeaways

- A computer is made up of multiple components working together.
- Different types of computers are designed for different purposes.
- Linux is an important operating system in cybersecurity.
- The Linux terminal provides powerful ways to interact with a system.
- Understanding the underlying system is important before learning how to
  attack or secure it.
- Linux knowledge will be useful throughout my future CTF challenges.

## Learning Approach

My approach is to learn the fundamentals first and then apply them through
hands-on challenges.

I am focusing on understanding concepts rather than simply memorizing
commands or following walkthroughs.
