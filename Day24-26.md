### Unified Kill Chain

The Unified Kill Chain describes an attack as a series of phases rather than treating an attack as a single exploit.

Reconnaissance → Weaponization → Social Engineering → Exploitation → Persistence → Defence Evasion → Command & Control → Pivoting → Discovery → Privilege Escalation → Execution → Credential Access → Lateral Movement → Collection → Exfiltration → Impact → Objectives

### In / Through / Out

**IN**
- Gain an initial foothold

**THROUGH**
- Move through and expand within the environment

**OUT**
- Achieve the attacker's objective

### Key Lesson

An attack is a chain of actions, not just a single exploit. The Unified Kill Chain helps understand how attackers progress through an environment and where defenders could detect or interrupt the attack.

### Attack Chain

Nmap → Service enumeration → FTP / Web investigation → Username discovery → Credential discovery → Hash / password cracking → ZIP cracking → Steganography → SSH access → Linux enumeration → CVE research → Privilege escalation → Root

### Key Lesson

Agent Sudo reinforced the importance of following clues throughout a CTF.

A single discovery can lead to another stage:

Username → Password discovery → Archive → Hidden information → Credentials → SSH → Privilege escalation

Instead of randomly trying exploits, continuously ask:

> What did I just discover, and what can this information lead to?

### Important Takeaway

> Enumerate first, follow the evidence, and enumerate again after gaining access.
