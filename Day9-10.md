## What I Learned

### 1. Nmap Fundamentals

I learned how Nmap is used for network reconnaissance and enumeration.

Key areas included:

- Host discovery
- Port scanning
- Open, closed, and filtered ports
- Service enumeration
- Operating system detection
- Understanding Nmap scan results

### 2. Nmap Scripting Engine (NSE)

I learned how the Nmap Scripting Engine extends Nmap beyond basic port scanning.

I practiced searching the Nmap scripts directory:

```bash
ls /usr/share/nmap/scripts/ | grep smb
```

NSE scripts can be used for:

- Service enumeration
- Information gathering
- Vulnerability discovery
- Authentication testing
- Brute-force testing
- Network discovery

### 3. SMB OS Discovery

I investigated the SMB NSE script:

```text
smb-os-discovery.nse
```

The script attempts to determine information about an SMB server, including:

- Operating system
- Computer name
- Domain
- Workgroup
- FQDN
- NetBIOS information
- System time

By reading the script source, I identified its dependency:

```text
smb-brute
```

### 4. ICMP Host Discovery

I learned that a target can be online while refusing ICMP echo requests.

This can cause Nmap to report that a host appears down even though services are running.

I learned how the `-Pn` option can be used to skip host discovery and treat the target as online.

### 5. Xmas Scan

I learned about the Xmas scan:

```bash
nmap -sX
```

I performed an Xmas scan against the first 999 ports.

I learned about the `open|filtered` state and how a lack of response can make it difficult for Nmap to distinguish between an open and filtered port.

### 6. TCP SYN Scan

I learned how to perform a TCP SYN scan:

```bash
nmap -sS
```

I also practiced scanning a specific range:

```bash
nmap -sS -p 1-5000 TARGET_IP
```

The scan identified the open TCP ports on the target.

### 7. Firewall Evasion

I learned how firewalls and packet filtering can affect Nmap scan results.

Different scan techniques can produce different results depending on how the target and network defenses handle packets.

### 8. TCP Connect Scan

I learned about TCP Connect scanning and how it differs from a SYN scan.

A TCP Connect scan completes the TCP connection, while a SYN scan normally does not complete the connection.

I also learned how Wireshark can be used to observe the packets involved in a TCP scan.

### 9. FTP Enumeration

I used the `ftp-anon` NSE script to test whether anonymous FTP access was available.

This demonstrated how Nmap scripts can automate service-specific enumeration.

## Key Takeaways

- Nmap is a fundamental reconnaissance and enumeration tool.
- Different scan types provide different information.
- NSE greatly expands Nmap's capabilities.
- Reading NSE source code helps understand what a script actually does.
- `-sX` performs an Xmas scan.
- `-sS` performs a TCP SYN scan.
- `-Pn` skips host discovery.
- `open|filtered` means Nmap cannot confidently distinguish between the two states.
- Firewall behavior can significantly affect scan results.
- Enumeration should be systematic and based on evidence from scan results.
