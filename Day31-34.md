## What I Learned

### 1. Understanding Logs
Logs are records generated by systems, applications, and network devices that document events and activities.

They can contain information such as:

- User activity
- Login attempts
- Network connections
- Application events
- Errors and warnings
- System changes
- Security events

### 2. Importance of Logs in Cybersecurity
Logs provide evidence of what happened on a system.

They are useful for:

- Security monitoring
- Incident investigation
- Threat hunting
- Troubleshooting
- Detecting suspicious activity
- Reconstructing attack timelines

### 3. Common Log Sources

- System logs
- Authentication logs
- Application logs
- Web server logs
- Firewall logs
- Network logs
- Security logs

Different sources provide different perspectives of an incident.

### 4. Authentication Logs

Authentication logs can reveal:

- Successful logins
- Failed login attempts
- Username involved
- Source IP address
- Authentication method
- Login timestamps

Repeated failed authentication attempts can be an indicator worth investigating.

### 5. Reading Log Entries

When investigating a log entry, important fields can include:

- Timestamp
- Source
- Destination
- Username
- IP address
- Event/action
- Status
- Message

The goal is not simply to read individual entries, but to connect events together and understand what happened.

### 6. Log Investigation

A useful investigation process is:

**Collect → Filter → Identify → Correlate → Investigate → Conclude**

Instead of looking at thousands of events individually, investigators filter logs for relevant users, IPs, timestamps, events, and suspicious activity.

### 7. Logs and Threat Hunting

Logs are an important source of evidence during threat hunting.

A hunter can use logs to investigate:

- Suspicious authentication
- Unusual network activity
- Abnormal user behavior
- System changes
- Possible compromise
- Indicators of compromise (IoCs)

This connects directly with the threat-hunting concepts learned previously.

## Key Takeaways

- Logs are records of events occurring within systems and applications.
- Different systems generate different types of logs.
- Authentication logs are particularly useful for investigating account activity.
- Timestamps, IP addresses, usernames, actions, and status fields are important investigation clues.
- Log analysis is about finding relationships between events rather than examining events in isolation.
- Logs provide valuable evidence for incident response and threat hunting.
