### MITRE ATT&CK

MITRE ATT&CK provides a structured way to describe adversary behaviour.

Attacker Behaviour → Tactic → Technique → Sub-technique

This allows security teams to describe, investigate, and detect attacker activity using a common framework.

### ATT&CK Navigator

Practiced using the MITRE ATT&CK Navigator to visualize techniques used by attackers.

Threat / Attacker → Identify Techniques → Map Techniques to ATT&CK → Visualize with Navigator → Investigate / Hunt

### Threat Hunting

Threat hunting is a proactive approach to finding suspicious or malicious activity instead of waiting for an alert.

A basic hunting process:

Hypothesis → Collect Data → Search / Investigate → Identify Suspicious Activity → Investigate Further → Confirm or Reject Hypothesis

### Key Lesson

Threat hunting combines threat intelligence, attacker behaviour, and security telemetry to proactively search for threats that may not have triggered existing security alerts.
